# 그린테이블 홈페이지 : created by jihyun

신선한 샐러드와 건강한 한 끼를 소개하는 반응형 브랜드 홈페이지입니다. 연한 그린과 아이보리 컬러, 큼직한 타이포그래피, 음식 사진을 중심으로 구성했습니다.

## 주요 섹션

- **메인 비주얼**: 브랜드 슬로건과 메뉴로 이동하는 버튼
- **BEST MENU**: 대표 메뉴를 가로로 둘러보는 슬라이더
- **FRESH PICKS**: 메뉴와 가격을 보여주는 그리드
- **브랜드 소개 및 스토리**: 브랜드의 재료와 식사에 대한 철학
- **매장·창업 안내 및 고객센터**: 전화, 문자 문의와 페이지 내 이동 링크
- **푸터**: 브랜드 정보, SNS 링크, 운영자 연락처

## 주요 기능

- 화면 크기에 맞춰 레이아웃이 바뀌는 반응형 디자인
- 모바일 햄버거 메뉴
- BEST MENU 좌우 버튼 및 마우스 드래그 탐색
- 스크롤 시 콘텐츠 등장 애니메이션
- 전화·문자 링크를 통한 모바일 문의

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다. `index.html`을 브라우저에서 열면 홈페이지를 확인할 수 있습니다.

음식 사진은 Unsplash에서 불러오므로 이미지 표시에는 인터넷 연결이 필요합니다.

## 파일 구성

```text
week11/
├── index.html   # 홈페이지의 HTML, CSS, JavaScript
├── README.md    # 프로젝트 안내
└── hello.js     # 별도의 JavaScript 실습 파일
```

CSS와 JavaScript는 별도 빌드 도구 없이 실행할 수 있도록 `index.html` 안에 작성되어 있습니다.

## 참고

- 푸터의 운영자 정보와 전화번호는 홈페이지에 표시되는 문의 정보입니다.
- 이용약관 및 개인정보처리방침 문구는 안내용 초안이므로 실제 서비스 공개 전 검토가 필요합니다.
